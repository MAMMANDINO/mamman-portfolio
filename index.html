From Raw Data to AI-Assisted Business Insights

AI does not replace accurate calculations. I use SQL and spreadsheet tools to establish the numbers, then AI to assist with interpreting qualitative information and communicating findings.

STEP 1 — DATA ANALYSIS SQL / MySQL

Extract products with elevated return rates and rank them by refund value. 

SELECT
    sku_id,
    category,
    return_count,
    net_refund_val,
    return_rate
FROM ecommerce_returns
WHERE return_rate > 0.10
ORDER BY
    net_refund_val DESC;
